# Research attempts

Store one attempt per `ATT-*.json` file, using its stable ID as the filename. An attempt can address any candidate, whether or not it has a full card. Its target, assumptions, success criteria, resources and verification plan must stand on their own.

The [progress page](../../docs/progress.md) lists recorded attempts and their review status. Drafts belong in `work/`; adding a draft does not run a model or create a research result.

See the [maintenance reference](../../docs/maintaining.md), [attempt schema](../../schemas/attempt.schema.json) and [contribution guide](../../CONTRIBUTING.md).
