# Research reviews

Store one review per `REV-*.json` file, using its stable ID as the filename. Reviews can address a candidate, a proposed method or an attempted result. Each identifies its reviewer, scope, evidence and the exact version examined.

The [progress page](../../docs/progress.md) lists recorded reviews. Editorial literature checks are stored separately in `data/literature-checks.json`.

See the [review guide](../../docs/review-guide.md), [review schema](../../schemas/review.schema.json) and [maintenance reference](../../docs/maintaining.md).
