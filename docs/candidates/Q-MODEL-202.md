# Complete EFX for more than four common bi-valued chore agents

For every n≥5, finite chore set M and common real ratio r>2, with additive costs c_i(g)∈{1,r} for every agent i and chore g, must there be a complete partition X with c_i(X_i\{g})≤c_i(X_j) for all i,j and every g∈X_i? Empty bundles impose no deletion comparison. No Pareto-optimality condition is required.

**Origin:** Literature-origin question. **Curator-designed scope:** No.

**Current status:** Source reports open. **Last checked:** 2026-10-14.

**Status basis:** He and Tao explicitly leave the more-than-four-agent common bi-valued case open. Their r≤2 case works for any n; m≤2n is also known. No later general resolution was located. Particular bounded pilots may already be known.

**Statement check:** Source located. **Status check:** Source report only.
