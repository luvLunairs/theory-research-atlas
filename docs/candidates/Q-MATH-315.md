Is there an algorithm that, given any knot diagram, terminates and returns its unknotting number, the minimum crossing changes needed to obtain the unknot?

**Origin:** Literature-origin question. **Curator-designed scope:** No.

**Current status:** Source reports open. **Last checked:** 2026-10-14.

**Status basis:** The 2026 K3 author version retains this question; scoped searches did not establish a general resolution. This is source-reported open status. Algorithms yielding upper bounds or solving selected knots do not settle computability.

**Statement check:** Source located. **Status check:** Source report only.

**Source date and freshness:** Recorded source years: SRC-MATH-303: 2026. The last-checked date records the scope described in the status basis; it is not a comprehensive literature-search date.

**Scope limits:** The statement and locator identify the candidate. A full assumption set and verification protocol remain to be documented.

**Primary branch:** [Low-dimensional topology](../domains/math.md#math-top-low). **Related branches:** [Computability and degree theory](../domains/logic.md#logic-recur), [Computational geometry and topology](../domains/cs.md#cs-geom).

**Sources:** [K3: A New Problem List in Low-Dimensional Topology](../sources.md#src-math-303).

**Exact locator:** K3 Problem 1.80; PDF p. 73.

**Potential difficulty:** Frontier. Searching crossing changes supplies upper bounds but does not give a terminating exact method for every knot.

**Possible AI role:** A tool-using AI could formalize the search space and inspect termination criteria or reductions for selected classes without mistaking a heuristic for an algorithm.

**Verification burden:** High. Exactness requires a matching lower bound or proof that the procedure always terminates with the minimum.

**Resource expectations:** Finite knot computations can be large; undecidability or termination arguments are logical proof tasks without a presumed budget.

**Assessment:** 2026-10-14; untested forecast. **Uncertainty:** A solution must address arbitrary diagrams, including knots with no currently effective lower-bound certificate.

**Further work:** define a scoped target, resource requirements and a verification plan before developing a full card. **Human review:** Pending.
