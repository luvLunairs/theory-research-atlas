Does every finite-player quitting game with at least four players admit an epsilon-Nash equilibrium for every epsilon>0? Each player independently randomizes a quitting time in N∪{infinity}; bounded payoffs depend on the first quitting set, with a specified payoff if nobody quits. External public correlation is not allowed.
