For a finite connected closed orientable triangular simplicial surface with nondegenerate Euclidean faces, set d(v)=2*pi-sum_(f incident to v) angle_f(v). Prove sum_v d(v)=2*pi*(|V|-|E|+|F|). A computational illustration must also check the closed-manifold incidence conditions; a mesh with boundary requires a different boundary contribution.
