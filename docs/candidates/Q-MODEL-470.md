**Origin:** Literature-origin question. **Curator-designed scope:** No.

**Current status:** Unverified. **Last checked:** 2026-11-06.

**Status basis:** The 2026 theorem concerns a modified system with v>1/2 and therefore does not cover general relativity at v=1/2. It cannot resolve the original question of equality with the full generic Mixmaster attractor.

**Statement check:** Needs clarification. **Status check:** Later literature checked.

**Source date and freshness:** The 2026-11-06 literature check identifies the versions and passages inspected; original publication dates and earlier checks remain relevant.

**Scope limits:** A mathematical question for specified Einstein equations, matter model and asymptotics. A theorem about these equations does not establish the empirical correctness of the assumptions; observational tests are separate.

**Information still needed**

- Compare claims for the GR system with modified-gravity parameter ranges; convergence to a containing set is not an equality theorem.
