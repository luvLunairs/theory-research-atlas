Let S include each positive integer n independently with probability omega(n)/n, where omega(n) tends to infinity and 0<=omega(n)<=n. Is S almost surely a set of r-recurrence for every fixed r: every positive-upper-density subset of N contains an (r+1)-term arithmetic progression with positive difference in S?
