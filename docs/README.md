# Browse the atlas

Choose a subject, then open a question to read its statement, sources and evidence limits. A **full card** also gives assumptions, possible methods, resource needs and a checking plan. You can browse and contribute through GitHub without installing anything.

**16 main domains · 113 subjects and subfields · 399 source records · 552 candidate records · 45 full cards.** The cards are included in the 552 candidates.

## Choose a way to help

| If you want to… | Start here |
| --- | --- |
| Explore a research question | [Open research candidates](research-candidates.md), with detailed tasks first; [difficulty view](difficulty.md) for a wider comparison. |
| Check a source, clarify a statement or update a status | [Questions awaiting checks](pending-checks.md). Each entry explains the missing information and links to a correction form. |
| Share an idea, result or review | [Contribute](../CONTRIBUTING.md). A concise explanation with sources is enough to start; a complete problem card is not required. |

Checking references and improving explanations are useful contributions in their own right. [Recorded progress](progress.md) includes unsuccessful work and partial results when available.

| Collection layer | What it provides | Limits |
| --- | --- | --- |
| A · Sources | Papers, surveys, problem collections and research communities. | A collection has not necessarily been fully read or indexed. |
| B · Candidates | A target, its origin, evidence status and brief difficulty profile. | An outline is not a full methods, resource or verification assessment. |
| C · Full cards | Assumptions, methods, resources and a validation plan. | A card is not a solution or expert endorsement. AI forecasts still require testing. |

Domain counts include their branches. Cross-links reuse existing questions; cards are included in question counts. Source counts include separately cited versions and cannot be summed across domains. Zero marks a coverage gap, not a field without useful research.
